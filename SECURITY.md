# Security

Do not report security-sensitive findings in a public issue, pull request, discussion, commit message, or Actions log.

If GitHub offers private vulnerability reporting for this repository, use that channel. If it is not available, contact Pajic LLC through a private business contact channel before sharing technical details publicly.

Include the affected commit or version, the impact, and the smallest reproducible case you can provide safely.

Do not include real credentials, private keys, signing material, personal data, or third-party confidential information in a report.
